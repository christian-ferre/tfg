# TFG - Balance de blancos en fotografía cuando hay más de una iluminación
### Código
- main.py
Codigo que se contiene una variable de la clase Illuminant_estimation() y ejecuta las funciones de generar los resultados y compararlos.
- tfg.py
Contiene la clase Illuminant_estimation(), la cual contiene todos los metodos que realizan el balance de blancos.
- Recortar.py
Se utiliza para extraer y guardar los diferentes puntos de las imágenes.
- Crear imagenes.py
Frame que se utiliza para crear imagenes para el Informe del tfg.
### Requisitos

- opencv-python==4.6.0.66

- numpy
- rawpy==0.18.1
